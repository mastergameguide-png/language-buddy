# language-buddy
AI language practice buddy

เพื่อน AI ไว้คุยฝึกภาษาบน iPhone ใช้ได้ฟรีทั้งหมด (Gemini free tier + Cloudflare Workers + GitHub Pages)

## ทำอะไรได้บ้าง

- แชตกับเพื่อน AI ที่มีชื่อและนิสัยของตัวเอง ตอบสั้นๆ เหมือนแชตจริง
- แก้ไวยากรณ์ใต้ข้อความของคุณ พร้อมอธิบายสั้นๆ เป็นภาษาไทย
- กดไมค์พูดได้ และเพื่อนจะอ่านคำตอบออกเสียง (แตะข้อความเพื่อฟังซ้ำ)
- จำเรื่องที่คุณเล่าไว้ (เช่น ชอบตกปลา) และเก็บคำที่พลาดไว้ใน "สมุดคำที่พลาด"
- ถ้าหายไปเกิน 3 ชั่วโมง พอเปิดแอปใหม่ เพื่อนจะทักก่อน
- ปุ่ม "ให้เพื่อนทดสอบคำที่พลาด" สำหรับทบทวน
- ปุ่ม 📷 ส่งรูป (ถ่ายใหม่หรือเลือกจากอัลบั้ม) ให้เพื่อนชวนคุยและสอนคำศัพท์จากรูป แอปย่อรูปก่อนส่ง และไม่เก็บรูปไว้ในประวัติ
- แถบโควตาใต้ชื่อเพื่อน บอกว่าวันนี้ใช้ไปกี่ครั้ง เหลือเท่าไร และรีเซ็ตกี่โมง (ใส่ตัวเลขโควตาต่อวันในหน้าตั้งค่า)
- เลือกภาษาได้: อังกฤษ ญี่ปุ่น จีน เกาหลี ฝรั่งเศส สเปน เยอรมัน ระดับ A1–C1

ความจำและประวัติแชตเก็บอยู่ในมือถือของคุณเท่านั้น (ล้างได้ในหน้าตั้งค่า)

## ไฟล์ในโปรเจกต์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (หน้าจอ แชต เสียง ความจำ) |
| `manifest.json`, `sw.js`, `icons/` | ทำให้เพิ่มลงหน้าจอโฮมได้เหมือนแอปจริง |
| `worker/worker.js` | โค้ดตัวกลางบน Cloudflare ที่ซ่อน API key |

> ห้ามใส่ API key ลงในไฟล์ใดๆ ใน repo นี้ เพราะ repo เป็นสาธารณะ key อยู่ใน Cloudflare เท่านั้น

## ขั้นตอนติดตั้ง (ทำครั้งเดียว ประมาณ 20 นาที)

### 1. ขอ Gemini API key (ฟรี)

1. เข้า https://aistudio.google.com แล้วล็อกอินด้วยบัญชี Google
2. กด **Get API key** → **Create API key**
3. คัดลอก key เก็บไว้ (อย่าส่งให้ใคร)

### 2. สร้าง Cloudflare Worker (ฟรี)

1. สมัคร/ล็อกอินที่ https://dash.cloudflare.com
2. เมนูซ้าย **Workers & Pages** → **Create** → **Create Worker** (เลือกแบบ Hello World)
3. ตั้งชื่อ เช่น `language-buddy` แล้วกด **Deploy**
4. กด **Edit code** ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ `worker/worker.js` → กด **Deploy**
5. กลับไปหน้า Worker → **Settings** → **Variables and Secrets** → **Add**
   - Type: **Secret**, Name: `GEMINI_API_KEY`, Value: key จากข้อ 1
6. คัดลอกลิงก์ของ Worker (หน้าตาแบบ `https://language-buddy.ชื่อคุณ.workers.dev`)
7. ทดสอบ: เปิดลิงก์นั้นในเบราว์เซอร์ ต้องเห็นข้อความ `Language Buddy worker is running`

### 3. อัปโหลดไฟล์ขึ้น GitHub และเปิด GitHub Pages

ถ้าใช้ Claude Code: บอกมันว่า "commit and push to GitHub"

ถ้าอัปโหลดเองผ่านเว็บ:
1. เข้า repo `language-buddy` บน GitHub → **Add file** → **Upload files**
2. ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `icons` และ `worker`) ไปวาง → **Commit changes**

เปิด GitHub Pages:
1. ใน repo ไปที่ **Settings** → **Pages**
2. Source: **Deploy from a branch**, Branch: **main**, โฟลเดอร์ **/ (root)** → **Save**
3. รอ 1–2 นาที จะได้ลิงก์ เช่น `https://ชื่อคุณ.github.io/language-buddy/`

### 4. ล็อก Worker ให้ใช้ได้เฉพาะเว็บของคุณ (แนะนำ)

กลับไปที่ Worker → **Settings** → **Variables and Secrets** → **Add**
- Type: **Text**, Name: `ALLOWED_ORIGIN`, Value: `https://ชื่อคุณ.github.io` (ไม่ต้องมี `/language-buddy` ต่อท้าย)

กันไม่ให้คนอื่นเอา Worker ของคุณไปใช้จนโควตาหมด

### 5. ติดตั้งบน iPhone

1. เปิดลิงก์ GitHub Pages ใน **Safari** (ต้องเป็น Safari)
2. กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** (Add to Home Screen)
3. เปิดแอปจากไอคอน → กดรูปเฟือง → วางลิงก์ Worker จากขั้นที่ 2 → เลือกภาษา ระดับ ชื่อ นิสัย → **บันทึก**
4. เพื่อนจะทักมาก่อน เริ่มคุยได้เลย

ทางลัด: ตั้ง **Back Tap** (การตั้งค่า → การช่วยการเข้าถึง → สัมผัส → แตะด้านหลัง) หรือปุ่ม Action ให้เปิดแอปนี้ผ่าน Shortcuts

## ปัญหาที่เจอบ่อย

| อาการ | วิธีแก้ |
|---|---|
| ปุ่มไมค์ไม่ทำงาน | การตั้งค่า → Safari → ไมโครโฟน → อนุญาต หรือใช้ไมค์บนคีย์บอร์ด iPhone แทน |
| ไม่มีเสียงตอบ | ปิดโหมดเงียบ (สวิตช์ข้างเครื่อง) และเช็กว่าเปิด "อ่านคำตอบออกเสียง" ในตั้งค่า |
| เสียงไม่ค่อยเป็นธรรมชาติ | การตั้งค่า → การช่วยการเข้าถึง → เนื้อหาที่ถูกพูด → เสียง → ดาวน์โหลดเสียงแบบ Enhanced/Premium ของภาษานั้น |
| "โควตาฟรีหมด" | free tier จำกัดจำนวนครั้งต่อนาที/ต่อวัน รอสักครู่แล้วลองใหม่ |
| ตัวเลขโควตาไม่ตรงกับ AI Studio | แอปนับเฉพาะในเครื่องนั้น ถ้าใช้หลายเครื่อง ตัวเลขจริงดูที่ aistudio.google.com/rate-limit (รีเซ็ตเที่ยงคืนเวลาแปซิฟิก = 14:00–15:00 เวลาไทย) |
| ส่งรูปแล้ว AI ไม่พูดถึงรูป หรือขึ้น "Request too large" | โค้ด Worker ใน Cloudflare ยังเป็นเวอร์ชันเก่า เปิดลิงก์ Worker ต้องเห็น `"version":3` ถ้าไม่เห็น ให้วางโค้ดจาก `worker/worker.js` ใหม่แล้วกด Deploy |
| "User location is not supported" หรือ "Google ปฏิเสธการเชื่อมต่อชั่วคราว" | Google บล็อก IP ของ Cloudflare บางตัวเป็นครั้งคราว Worker ลองใหม่ให้อัตโนมัติ 5 ครั้งแล้ว ถ้ายังเจอให้กดส่งใหม่ |
| error ว่า model not found | ชื่อโมเดลของ Google อาจเปลี่ยน ดูชื่อล่าสุดใน AI Studio แล้วเพิ่มตัวแปร `GEMINI_MODEL` (Text) ใน Worker |
| "not allowed (check ALLOWED_ORIGIN)" | ค่า `ALLOWED_ORIGIN` ต้องตรงกับ `https://ชื่อคุณ.github.io` เป๊ะ |
| แก้โค้ดแล้วมือถือยังเห็นแบบเก่า | ปิดแอปแล้วเปิดใหม่ 1–2 ครั้ง หรือเปลี่ยน `CACHE` ใน `sw.js` เป็นเลขใหม่ |

## ขั้นต่อไป (ยังไม่ได้ทำ)

- **แจ้งเตือนทักมาก่อนแม้ไม่ได้เปิดแอป**: ใช้ Web Push + Cron Trigger ของ Cloudflare Workers (iOS 16.4 ขึ้นไป และต้องเพิ่มลงหน้าจอโฮมแล้ว)
- เสียงพูดที่เป็นธรรมชาติขึ้น
