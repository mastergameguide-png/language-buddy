# language-buddy
AI language practice buddy

เพื่อน AI ไว้คุยฝึกภาษาบน iPhone ใช้ได้ฟรีทั้งหมด (Gemini free tier + Cloudflare Workers + GitHub Pages)

## ทำอะไรได้บ้าง

แอปมี 6 หน้า (เมนูด้านล่างบนมือถือ / ด้านซ้ายบนคอม):

| หน้า | มีอะไร |
|---|---|
| 🏠 หน้าหลัก | เป้าหมายวันนี้ วันเรียนต่อเนื่อง 🔥 เวลาเรียน คำศัพท์ ความแม่นยำไวยากรณ์ แผนแนะนำตามจุดอ่อน กราฟ 7 วัน กิจกรรมล่าสุด |
| 💬 แชต | คุยกับตัวละคร AI 6 คน (หรือเพื่อนที่สร้างเอง) แต่ละคนมีห้องแชตของตัวเอง · 4 โหมด (คุยธรรมชาติ / เรียนไปคุยไป / เน้นแก้ภาษา / ฝึก IELTS) · คำแก้แยกเป็น ผิด / ไม่เป็นธรรมชาติ / ทางเลือก พร้อมคำแปล เลือกได้ว่าจะดูทันที ย่อไว้ หรือดูตอนท้าย · 💡 "ลองตอบ" 3–4 แบบ · 🆘 คำใบ้ 4 ขั้น (คำใบ้ → คำศัพท์ → รูปประโยค → ตัวอย่าง) · 🇹🇭→EN พิมพ์ไทยแล้วให้ช่วยพูดเป็นอังกฤษ · ส่งรูป พูดด้วยเสียง |
| 👥 ตัวละคร | (แตะชื่อบนหัวแชต) เลือกตัวละคร ดูโปรไฟล์ บทบาทที่เล่นได้ และลบความจำของแต่ละตัว |
| 🧠 ทบทวน | ทบทวนแบบเว้นระยะ (Spaced Repetition) · คลังคำศัพท์ · สมุดผิดพร้อมค้นหาและกรองตามประเภท/สถานะ |
| 🎭 สถานการณ์ | 25 สถานการณ์ 13 หมวด ค้นหาและกรองตามหมวด/ระดับได้ · เลือกความยาก ง่าย/ปกติ/ยาก · ระหว่างเล่นเห็นว่าถึงขั้นไหน · จบแล้วได้คะแนนรวมและคะแนนแยกตามเกณฑ์ เทียบกับครั้งก่อน และเล่นซ้ำได้ + สร้างเอง |
| 🎙️ ฝึกเสียง | พูดตามประโยคจากสมุดผิด คลังคำ แชต และสถานการณ์ (ฟัง / ฟังช้า / ทีละท่อน) · ดูว่าเครื่องจับคำได้กี่คำ (ไม่ใช่คะแนนการออกเสียง) · อัดเสียงตัวเองฟังเทียบ · ฝึกฟัง: เติมคำและพิมพ์ตามเสียง |
| 📈 รายงานและแผน | (จากหน้าหลักหรือหน้าฉัน) แผน 7 วันที่แก้ได้ ความคืบหน้านับจากสิ่งที่ทำจริง · แนะนำสิ่งที่ควรทำต่อพร้อมเหตุผล · สัปดาห์นี้เทียบสัปดาห์ก่อน ทุกตัวเลขบอกที่มาและแสดงเมื่อข้อมูลพอ · ประวัติ 30 วัน |
| 👤 ฉัน | ความก้าวหน้า ทักษะ 5 ด้าน (จากข้อความ) พร้อมแนะนำให้ขยับระดับ จุดที่ควรฝึก ความจำร่วม (ลบได้) และตั้งค่า |

รายละเอียดฟีเจอร์:

- แชตกับเพื่อน AI ที่มีชื่อและนิสัยของตัวเอง ตอบสั้นๆ เหมือนแชตจริง
- แก้ไวยากรณ์ใต้ข้อความของคุณ พร้อมอธิบายสั้นๆ เป็นภาษาไทย
- กดไมค์พูดได้ และเพื่อนจะอ่านคำตอบออกเสียง (แตะข้อความเพื่อฟังซ้ำ)
- จำเรื่องที่คุณเล่าไว้ (เช่น ชอบตกปลา) และเก็บคำที่พลาดไว้ใน "สมุดคำที่พลาด"
- ถ้าหายไปเกิน 3 ชั่วโมง พอเปิดแอปใหม่ เพื่อนจะทักก่อน
- 🔔 **ทักมาก่อนผ่านการแจ้งเตือน** แม้ไม่ได้เปิดแอป เลือกได้ 2 แบบ: 🎲 สุ่มวันละ 1–3 ครั้งในช่วงเวลาที่เลือก หรือ 🕐 กำหนดเวลาเอง สูงสุด 3 เวลา (มาช้าได้ไม่เกิน 10 นาที)
- 🎭 **ฝึกสถานการณ์จริง** 25 แบบ (เช่น คาเฟ่ ร้านอาหาร โรงแรม ตม. ถามทาง สัมภาษณ์งาน หาหมอ คลินิกสัตว์ ฉุกเฉิน แจ้งตำรวจ) หรือพิมพ์สถานการณ์เอง จบแล้วได้คำแนะนำเป็นภาษาไทย
- 🤖 **ใช้ 2 AI สลับกันอัตโนมัติ**: Gemini เป็นหลัก (เก่งภาษาไทยและดูรูปได้) ถ้าโควตาหมดหรือ Google ปฏิเสธ จะสลับไป Groq เอง ข้อความทักผ่านแจ้งเตือนใช้ Groq ก่อนเพื่อประหยัดโควตา Gemini (เลือกได้ใน ตั้งค่า → AI ที่ใช้คุย)
- 💾 **สำรองข้อมูล** ส่งออกเป็นไฟล์ แล้วนำเข้ากลับมาได้ (ตั้งค่า → สำรองข้อมูล)
- ปุ่ม "ให้เพื่อนทดสอบคำที่พลาด" สำหรับทบทวน
- ปุ่ม 📷 ส่งรูป (ถ่ายใหม่หรือเลือกจากอัลบั้ม) ให้เพื่อนชวนคุยและสอนคำศัพท์จากรูป แอปย่อรูปก่อนส่ง และไม่เก็บรูปไว้ในประวัติ
- แถบโควตาใต้ชื่อเพื่อน บอกว่าวันนี้ใช้ไปกี่ครั้ง เหลือเท่าไร และรีเซ็ตกี่โมง (ใส่ตัวเลขโควตาต่อวันในหน้าตั้งค่า)
- เลือกภาษาได้: อังกฤษ ญี่ปุ่น จีน เกาหลี ฝรั่งเศส สเปน เยอรมัน ระดับ CEFR A1–C2
- ภาษาอังกฤษเลือกระดับเป็น **IELTS band 3.5–9.0** ได้ (ตัวละครใช้คำให้ตรง band และค่อยๆ ดันไป band ถัดไป) และเลือก **🇺🇸 อเมริกัน / 🇬🇧 บริติช** ได้ ทั้งการสะกด คำศัพท์ สำนวน และเสียงพูด
- 🎓 **สอบพูด IELTS จำลอง** (Part 1–3) ในโหมดฝึกสถานการณ์ จบแล้วได้ band โดยประมาณแต่ละหัวข้อเป็นภาษาไทย — **เป็นการประมาณจากคำตอบที่พิมพ์ ไม่ใช่คะแนนสอบ IELTS จริง** และยังไม่ได้ประเมินการออกเสียง

ความจำและประวัติแชตเก็บอยู่ในมือถือของคุณ (แชตเก็บล่าสุด 500 ข้อความต่อตัวละคร คำศัพท์และสมุดผิดเก็บได้ถึง 5,000 รายการ ถ้าเกินจะแจ้งในหน้าตั้งค่า และดูพื้นที่ที่ใช้ได้ที่นั่น) (ล้างได้ในหน้าตั้งค่า) ถ้าเปิดซิงก์ ข้อมูลจะมีสำเนาใน Cloudflare D1 ด้วย (ดูหัวข้อซิงก์) ถ้าเปิดการแจ้งเตือน Worker จะเก็บสำเนาเล็กๆ ไว้ใน Cloudflare KV ด้วย (ชื่อ/นิสัยเพื่อน เรื่องที่จำได้ 20 ข้อ และ 6 ข้อความล่าสุด) เพื่อใช้เขียนข้อความทัก กด "ปิด" การแจ้งเตือนแล้วข้อมูลนี้จะถูกลบ

## ระบบตัวละคร AI (Living AI Characters)

ตัวละครทั้งหมดเป็นตัวละคร AI สมมติ และจะบอกตรงๆ ว่าเป็น AI เมื่อถูกถาม

| ตัวละคร | อายุ | แนว | บทบาทที่เล่นได้ |
|---|---|---|---|
| Emma 🇺🇸 | 24 | เพื่อนสนิท ขี้เล่น | เพื่อน · ลูกค้าคาเฟ่ · เพื่อนร่วมทริป · ผู้สัมภาษณ์งาน |
| James 🇺🇸 | 28 | มืออาชีพ | เพื่อนร่วมงาน · ผู้สัมภาษณ์ · หัวหน้า · คู่ค้า |
| Mika | 25 | นักเดินทาง | เพื่อนร่วมทริป · พนักงานโรงแรม · เจ้าหน้าที่สนามบิน · นักท่องเที่ยว |
| David 🇬🇧 | 35 | ครูพี่เลี้ยง | ครู · โค้ชไวยากรณ์ · ผู้คุมสอบพูด · ติวเตอร์คำศัพท์ |
| Sofia 🇦🇺 | 26 | สาวสังคม | เพื่อนใหม่ · บาริสต้า · พนักงานร้านอาหาร · พนักงานขาย |
| Alex 🇨🇦 | 32 | ครูฝึกการสื่อสารฉุกเฉิน | ครูฝึก · ตำรวจ · พยาน · นักท่องเที่ยวต่างชาติ |

**ทำงานยังไง** — ทุกครั้งที่ส่งข้อความ prompt = **บุคลิกหลัก** (ไม่เปลี่ยน) + **บทบาทตอนนี้** + **อารมณ์ตอนนี้** + **บริบท** (ความจำ ระดับ สถานการณ์)

- **บทบาท**: ลำดับความสำคัญ = สถานการณ์ที่คุณเลือก > บทบาทที่คุณเลือกเอง > บทบาทที่ AI ตรวจจับได้ (เช่น "ขอซ้อมสัมภาษณ์") > บทบาทปกติ · เปลี่ยนเองได้ที่แถบ 🎭 ใต้หัวแชต · ไม่คุยเกิน 6 ชั่วโมงจะกลับเป็นปกติ (ยกเว้นกำลังเล่นสถานการณ์)
- **อารมณ์** 8 แบบ ความแรง 0–1: AI เสนอ แต่แอปตัดสิน — เปลี่ยนเมื่อมีเหตุผลพอ ค่อยๆ เปลี่ยน ไม่เกินเพดานของตัวละคร (ตัวละครใจเย็นอย่าง David/Alex เปลี่ยนยากกว่า) มีผลกับคำพูด น้ำเสียง และรูปตัวละคร
- **ความจำ 3 ชั้น**: ความจำร่วม (เรื่องของคุณ ทุกตัวเห็น) · ความจำของแต่ละตัว (แยกกัน เลือกมาเฉพาะเรื่องที่เกี่ยวข้อง 6 ข้อ ไม่ใช้ 180 วันจะหมดอายุ) · ความจำของรอบสนทนา (บทบาท อารมณ์ หัวข้อ สรุปย่อ) — ไม่ซ้ำ ไม่เก็บรหัสผ่าน/ตัวเลข/อีเมล ปิดและลบได้
- **คำตอบมีโครงสร้าง** (`character_id`, `message`, `emotion`, `active_role`, `language_feedback`, `suggested_replies`, `memory_updates`, `topic`, `summary`, `assessment`) แอปตรวจทุกช่องก่อนใช้ ข้อความที่เสียแสดงเป็นข้อความธรรมดา ไม่มีช่องไหนสั่งให้แอปทำอะไรได้เอง
- **ระดับ CEFR**: ความยาวประโยค คำศัพท์ คำถาม และความเร็วเสียง (A1 ช้าลง 20%) ปรับตามระดับ หน้า ฉัน แนะนำให้ขยับระดับเมื่อคะแนนสูง/ต่ำต่อเนื่อง (คุณเป็นคนกดเปลี่ยน)

### ไฟล์ของระบบตัวละคร (`js/engine/` ไม่มีโค้ดหน้าจอ ทดสอบใน Node ได้)

| ไฟล์ | หน้าที่ |
|---|---|
| `characters.js` | ข้อมูลตัวละคร 6 ตัว + เพื่อนที่สร้างเอง + รายการบทบาท (แก้ตัวละครที่นี่ที่เดียว) |
| `roles.js` | สลับบทบาทและลำดับความสำคัญ |
| `emotion.js` | เลือกอารมณ์ รูปตามอารมณ์ และน้ำเสียง |
| `memory.js` | จำ ตัดซ้ำ กรองข้อมูลส่วนตัว เลือกความจำที่เกี่ยวข้อง หมดอายุ |
| `scenarios.js` | 25 สถานการณ์ 13 หมวด (สภาพแวดล้อม บทบาท ระดับ เป้าหมาย คำศัพท์ ประโยคที่ใช้ได้ ขั้นตอน เงื่อนไขจบ เกณฑ์ประเมิน) + ความยาก ค้นหา และประวัติการฝึก |
| `response.js` | ตรวจคำตอบของ AI และซ่อม JSON ที่ผิดเล็กน้อย |
| `prompt.js` | ประกอบ prompt จากทุกส่วน |

**เพิ่มตัวละครใหม่**: เพิ่ม 1 รายการใน `CHARACTERS` (`js/engine/characters.js`) ให้ครบทุกช่อง แล้วรัน `node tests/engine.test.mjs` (มีตัวตรวจว่าข้อมูลครบ) · ใส่รูป: ดู `assets/characters/README.md`

### การทดสอบ

```
node tests/run-all.mjs            # ชุดทดสอบทั้งหมดที่ไม่ใช้เน็ต: ตัวละคร ข้อมูล Worker ซิงก์ แจ้งเตือน ความปลอดภัย
node tests/live-characters.mjs    # คุยกับ AI จริงผ่าน Worker (ใช้โควตาประมาณ 30 ครั้ง รันเมื่อจำเป็นเท่านั้น)
node tests/live-scenarios.mjs     # เล่นสถานการณ์กับ AI จริง (ประมาณ 25 ครั้ง)
```

## ไฟล์ในโปรเจกต์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | โครงหน้าจอทุกหน้าและฟอร์มตั้งค่า |
| `css/app.css` | Design system (สี ตัวอักษร ระยะห่าง ปุ่ม การ์ด) ธีมมืด/สว่าง |
| `js/main.js` | เริ่มแอป เปลี่ยนหน้า ป้ายแจ้งเตือนบนเมนู ดักข้อผิดพลาด |
| `js/store.js` | ข้อมูลและการตั้งค่า การย้ายข้อมูลจากเวอร์ชันเก่า ตรวจข้อมูลที่นำเข้า |
| `js/ai.js` | prompt ของติวเตอร์ ส่งคำขอ (หมดเวลา 45 วิ, ลองใหม่) ตรวจคำตอบ AI นับโควตา |
| `js/srs.js` · `js/stats.js` | ระบบทบทวนแบบเว้นระยะ · สถิติ (เวลา streak ความแม่นยำ) |
| `js/speech.js` · `js/push.js` | เสียงพูด/ฟัง · การแจ้งเตือน |
| `js/sync.js` | ซิงก์ข้ามเครื่อง: ส่งเฉพาะสิ่งที่เปลี่ยน รับของเครื่องอื่น รวมข้อมูลเข้าด้วยกัน |
| `js/engine/*.js` | ระบบตัวละคร (ดูหัวข้อด้านบน) |
| `js/views/*.js` | แต่ละหน้า: home, chat, characters, review, roleplay, me, settings · `avatar.js` รูปตัวละคร |
| `tests/` | ชุดทดสอบ (`run-all.mjs` รันทุกไฟล์ `*.test.mjs` · GitHub Actions รันให้ทุกครั้งที่ push) |
| `docs/` | ผลตรวจระบบ สถาปัตยกรรม แผนพัฒนา บันทึกการเปลี่ยนแปลง และผลทดสอบ |
| `assets/characters/` | ที่วางรูปตัวละคร (ยังไม่มีรูป ใช้ตัวอักษรแทน) |
| `manifest.json`, `sw.js`, `icons/` | ทำให้เพิ่มลงหน้าจอโฮมได้เหมือนแอปจริง |
| `worker/worker.js` | โค้ดตัวกลางบน Cloudflare: ซ่อน API key, ระบบแจ้งเตือน และตัวตั้งเวลาทัก |
| `worker/wrangler.toml` | การตั้งค่า deploy (ทำงานที่สหรัฐฯ, KV, ตั้งเวลาทุก 10 นาที) |
| `worker/schema.sql` | ตารางของฐานข้อมูล SQL (Cloudflare D1) สำหรับซิงก์ |
| `worker/make-vapid.mjs` | สร้างกุญแจสำหรับการแจ้งเตือน (ใช้ครั้งเดียว) |

> ห้ามใส่ API key ลงในไฟล์ใดๆ ใน repo นี้ เพราะ repo เป็นสาธารณะ key อยู่ใน Cloudflare เท่านั้น

## ขั้นตอนติดตั้ง (ทำครั้งเดียว ประมาณ 20 นาที)

### 1. ขอ Gemini API key (ฟรี)

1. เข้า https://aistudio.google.com แล้วล็อกอินด้วยบัญชี Google
2. กด **Get API key** → **Create API key**
3. คัดลอก key เก็บไว้ (อย่าส่งให้ใคร)

### 2. สร้าง Cloudflare Worker (ฟรี)

1. สมัคร/ล็อกอินที่ https://dash.cloudflare.com
2. เมนูซ้าย **Workers & Pages** → **Create** → **Create Worker** (เลือกแบบ Hello World)
3. ตั้งชื่อ เช่น `language-buddy` แล้วกด **Deploy**
4. กด **Edit code** ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ `worker/worker.js` → กด **Deploy**
5. กลับไปหน้า Worker → **Settings** → **Variables and Secrets** → **Add**
   - Type: **Secret**, Name: `GEMINI_API_KEY`, Value: key จากข้อ 1
6. คัดลอกลิงก์ของ Worker (หน้าตาแบบ `https://language-buddy.ชื่อคุณ.workers.dev`)
7. ทดสอบ: เปิดลิงก์นั้นในเบราว์เซอร์ ต้องเห็นข้อความ `Language Buddy worker is running`

### 3. อัปโหลดไฟล์ขึ้น GitHub และเปิด GitHub Pages

ถ้าใช้ Claude Code: บอกมันว่า "commit and push to GitHub" และ deploy Worker ด้วย `npx wrangler deploy` ในโฟลเดอร์ `worker` (ครั้งแรกต้อง `npx wrangler login`)

ถ้าอัปโหลดเองผ่านเว็บ:
1. เข้า repo `language-buddy` บน GitHub → **Add file** → **Upload files**
2. ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `icons` และ `worker`) ไปวาง → **Commit changes**

เปิด GitHub Pages:
1. ใน repo ไปที่ **Settings** → **Pages**
2. Source: **Deploy from a branch**, Branch: **main**, โฟลเดอร์ **/ (root)** → **Save**
3. รอ 1–2 นาที จะได้ลิงก์ เช่น `https://ชื่อคุณ.github.io/language-buddy/`

### 4. ล็อก Worker ให้ใช้ได้เฉพาะเว็บของคุณ (แนะนำ)

กลับไปที่ Worker → **Settings** → **Variables and Secrets** → **Add**
- Type: **Text**, Name: `ALLOWED_ORIGIN`, Value: `https://ชื่อคุณ.github.io` (ไม่ต้องมี `/language-buddy` ต่อท้าย)

กันไม่ให้คนอื่นเอา Worker ของคุณไปใช้จนโควตาหมด

### 5. ติดตั้งบน iPhone

1. เปิดลิงก์ GitHub Pages ใน **Safari** (ต้องเป็น Safari)
2. กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** (Add to Home Screen)
3. เปิดแอปจากไอคอน → กดรูปเฟือง → วางลิงก์ Worker จากขั้นที่ 2 → เลือกภาษา ระดับ ชื่อ นิสัย → **บันทึก**
4. เพื่อนจะทักมาก่อน เริ่มคุยได้เลย

### 6. เปิดการแจ้งเตือนให้เพื่อนทักมาก่อน (ไม่บังคับ)

ฝั่ง Worker ต้องตั้งค่าครั้งเดียว (Claude Code ทำให้ได้ ในโฟลเดอร์ `worker`):
1. `npx wrangler kv namespace create BUDDY` แล้วใส่ id ที่ได้ใน `wrangler.toml`
2. `node make-vapid.mjs | npx wrangler secret put VAPID_PRIVATE_JWK`
3. `npx wrangler secret put INTERNAL_KEY` (ใส่ตัวอักษรสุ่มยาวๆ)
4. `npx wrangler deploy` แล้วเปิดลิงก์ Worker ต้องเห็น `"push":true`

บน iPhone (iOS 16.4 ขึ้นไป):
1. ต้องเปิดแอปจาก**ไอคอนบนหน้าจอโฮม** (ใน Safari ปกติเปิดการแจ้งเตือนไม่ได้)
2. กดรูปเฟือง → หัวข้อ 🔔 → **เปิดการแจ้งเตือน** → **อนุญาต**
3. เลือก "ให้ทักเมื่อไหร่" แบบสุ่มหรือกำหนดเวลาเอง
4. กด **ส่งทดสอบตอนนี้** ควรได้แจ้งเตือนภายในไม่กี่วินาที แตะแล้วข้อความจะอยู่ในแชต

### 7. เพิ่ม Groq เป็น AI ตัวที่สอง (ไม่บังคับ แต่แนะนำ)

1. สมัครและสร้าง API key ฟรีที่ https://console.groq.com/keys
2. ในโฟลเดอร์ `worker` รัน `npx wrangler secret put GROQ_API_KEY` แล้ววาง key (อย่าส่ง key ในแชตหรือใส่ในไฟล์)
3. เปิดลิงก์ Worker ต้องเห็น `"ai":["gemini","groq"]`
4. เปลี่ยนโมเดลได้ด้วยตัวแปร `GROQ_MODEL` (ค่าเริ่มต้น `openai/gpt-oss-120b`)

### 8. ซิงก์ข้ามเครื่องด้วยฐานข้อมูล SQL ฟรี (ไม่บังคับ)

ใช้ Cloudflare D1 (SQLite ฟรี 5GB) ตั้งค่าไว้แล้วใน `wrangler.toml` ถ้าจะทำใหม่ในบัญชีอื่น:
1. `npx wrangler d1 create language-buddy-db` แล้วเอา `database_id` ใส่ใน `wrangler.toml`
2. `npx wrangler d1 execute language-buddy-db --remote --file=schema.sql`
3. `npx wrangler deploy` แล้วเปิดลิงก์ Worker ต้องเห็น `"sync":true`

ในแอป: ฉัน → ตั้งค่า → ซิงก์ข้ามเครื่อง → **เปิดซิงก์** จะได้รหัส 20 ตัว เครื่องอื่นใส่รหัสนี้แล้วกด **เชื่อมกับเครื่องอื่น** ข้อมูลจะรวมกัน
- ซิงก์เองตอนเปิดแอป ตอนสลับแอป และทุก 3 นาที (ไม่รวมรูป ลิงก์ Worker และรหัสเข้าใช้)
- แก้สิ่งเดียวกันพร้อมกันสองเครื่อง: เครื่องที่ซิงก์ทีหลังชนะ · สถิติรายวันใช้ค่าที่มากกว่า
- เก็บรหัสซิงก์เป็นความลับ ใครมีรหัสก็อ่านข้อมูลได้ (เซิร์ฟเวอร์เก็บแค่ค่า hash ของรหัส)

ทางลัด: ตั้ง **Back Tap** (การตั้งค่า → การช่วยการเข้าถึง → สัมผัส → แตะด้านหลัง) หรือปุ่ม Action ให้เปิดแอปนี้ผ่าน Shortcuts

| ส่งรูปแล้ว AI ไม่พูดถึงรูป หรือฟีเจอร์ใหม่ไม่ทำงาน | Worker ใน Cloudflare ยังเป็นเวอร์ชันเก่า เปิดลิงก์ Worker ต้องเห็น `"version":9` ถ้าไม่เห็น ให้ deploy ใหม่ด้วย `npx wrangler deploy` (อย่าวางโค้ดในหน้า Edit code เพราะการตั้งค่าใน `wrangler.toml` จะไม่ไปด้วย) |

| "User location is not supported" หรือ "Google ปฏิเสธการเชื่อมต่อชั่วคราว" | Google บล็อก IP ของ Cloudflare ในเอเชีย `wrangler.toml` จึงตั้งให้ Worker ทำงานที่สหรัฐฯ (`[placement]`) ต้อง deploy ด้วย `npx wrangler deploy` ค่านี้จึงจะมีผล เช็กได้จาก header `cf-placement: remote-IAD` |

## ความปลอดภัย

- API key อยู่ใน Cloudflare Secrets เท่านั้น ไม่มีใน repo หรือหน้าเว็บ
- Worker รับเฉพาะเว็บที่ตั้งใน `ALLOWED_ORIGIN` จำกัด 40 คำขอ/นาที/IP และ (ถ้าตั้ง `ACCESS_CODE`) ต้องมีรหัสเข้าใช้
- คำขอไป AI หมดเวลาเอง (Gemini 22 วิ, Groq 18 วิ) แล้วสลับไปอีกตัว
- ข้อมูลซิงก์อยู่ใน D1 ของบัญชี Cloudflare คุณเอง แยกตามรหัสซิงก์ (เก็บเป็น SHA-256)
- ข้อความจาก AI ถูกตรวจรูปแบบและแสดงผลเป็นข้อความล้วน (ไม่มีการแปลงเป็น HTML) มี Content-Security-Policy

ตั้งรหัสเข้าใช้ (แนะนำ): ในโฟลเดอร์ `worker` รัน `npx wrangler secret put ACCESS_CODE` แล้วใส่รหัสเดียวกันใน แอป → ฉัน → ตั้งค่า → การเชื่อมต่อ

## ข้อจำกัดที่รู้อยู่

- **รูปตัวละคร**: ยังไม่มีรูปจริง แอปแสดงตัวอักษรย่อและสีประจำตัวแทน (ไม่ได้ใช้รูปปลอม) ระบบพร้อมรับรูป 6 อารมณ์ต่อตัว
- **การออกเสียง/การฟัง/การอ่าน**: ยังวัดไม่ได้ ทักษะ 5 ด้านประเมินจากข้อความที่พิมพ์เท่านั้น
- **เสียงตัวละคร**: ใช้เสียงที่มีในเครื่อง เลือกสำเนียงได้ (US/UK/AU/CA ถ้าเครื่องมี) แต่แยกเสียงชาย/หญิงไม่ได้แน่นอน
- **โมเดลฟรี**: บางครั้งยังทำตามกติกาไม่ครบ (เช่น ระดับ A1 อาจใช้คำยากบ้าง) แอปจึงตรวจซ้ำในส่วนที่ตรวจได้ (คำแก้ต้องตรงกับข้อความล่าสุด อารมณ์/บทบาทต้องอยู่ในรายการ)
- **ตัวละครกับภาษาอื่น**: ตัวละครพูดภาษาที่คุณเลือกได้ แต่บุคลิกและสำเนียงออกแบบมาสำหรับภาษาอังกฤษ
